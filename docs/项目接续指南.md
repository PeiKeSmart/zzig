# zzig · 项目接续指南

> **开工先读（存在则读，按序）**：`.github/copilot-instructions.md` → 本文 → `docs/用户档案.md` → `docs/项目记忆.md` → 决策/审计文档最新节。
> **机器自愈（有则快跑）**：`tools/continuity/install-global-instruction.ps1`（幂等；打开项目时 `.vscode/tasks.json` 也会自动跑）。

## 1. 项目速览

- 名称：`zzig`；目录 `G:\Code\Zig\zzig`；远端 `origin/main`。
- 定位：Zig 通用工具库（日志/字符串/文件/随机/控制台/JSON/XML/网络/HTTP/进程/菜单/输入/性能分析）。
  Zig 0.15.2+ 兼容（`build.zig` 按版本分派）。
- 2026-11-11 新增通用层（首个消费方 `Pek.ZCode`）：
  `zzig.Buf`（字符串缓冲）、`zzig.Decimal`（十进制）、`zzig.DateTime`（无时区时间）、
  `zzig.db.Value`（数据库值模型）、`zzig.db.sqlite`（SQLite 动态加载驱动）、
  `zzig.File.UniqueTempName` / `DeleteQuiet`（临时文件工具）。
- 仓库约定：`src/zzig.zig` 是模块根（统一在此转出）；单测在 `src/test.zig`（XML 另有 `src/xml_test.zig`）。

## 2. 常用命令（构建 / 测试 / 回归）

```powershell
zig build            # 编译（默认 install）
zig build test       # 全部单测（当前 51 项：主测试 24 + XML 27）
zig build xml-test   # 仅 XML 模块
zig build docs       # 生成文档
```

本仓无独立回归脚本，以 `zig build test` 作为回归门禁（退出码 0）。

## 3. 每轮收尾（务必）

① 决策/审计文档新增一节（**含用户原话**）——本仓约定：`docs/决策记录.md`（无则新建）；② 运行 `tools/continuity/sync-memory.ps1` 同步记忆（需在项目根目录运行或传 `-ProjectPath`）；③ 跑回归验证并如实汇报。
